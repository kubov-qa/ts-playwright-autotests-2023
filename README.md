TS + Playwright автотесты — Личный кабинет:
E2E автотесты для личного кабинета на TypeScript + Playwright. Примеры структуры тестов, паттернов и подходов.

О проекте:
Написал 50+ e2e автотестов, покрывающих ключевые сценарии личного кабинета. Тесты встроены в GitLab CI и прогоняются автоматически при каждом мердже — это помогло раньше отлавливать регрессии и повысило качество проекта.
Мои E2E можно найти в папке smart-lk.
